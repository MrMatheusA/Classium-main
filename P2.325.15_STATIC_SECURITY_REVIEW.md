## 3. Riscos Residuais e Salvaguardas

1. **Drift de Políticas Concorrentes:** Se uma migração concorrente criar uma política em `platform_members` antes da aplicação, o teste `v_pm_policy_count <> 1` abortará a execução sem alterar o banco.
2. **PostgREST Schema Cache:** A instrução `NOTIFY pgrst, 'reload schema'` assegura que os nós de API do PostgREST recarreguem suas definições de schema. Em caso de latência no listener, o endpoint RPC pode requerer alguns segundos para refletir a nova função sem parâmetros.
